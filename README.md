# Pizza-Sales-Dashboard--1
 Excited to Share My Data Analysis Project!  I recently completed a Pizza Sales Analysis Project using SQL and MS Excel.  


Successfully transformed raw pizza sales data into meaningful insights using SQL and Excel.
Developed an interactive dashboard to monitor key performance indicators (KPIs) like revenue, orders, and sales trends,
Identified top-performing and low-performing products, helping in better product planning,
Discovered peak sales hours and days, useful for improving operations and staffing decisions,
Analyzed customer preferences by category and size, supporting targeted marketing strategies,
Improved ability to perform data analysis, data visualization, and business insight generation,
Demonstrated an end-to-end data analysis workflow, from data extraction to decision-making.

#Business Recommendations from the Project
 ## 1. Improve Sales During Low Hours
Since analysis shows certain hours have low orders, introduce:
Discounts or combo offers during off-peak hours
“Happy Hours” to increase customer traffic
## 2. Focus on Top-Selling Pizzas
Promote best-selling pizzas more through:
Combos and deals
Featured items on menu/dashboard
Ensure these items are always in stock to avoid lost sales
## 3. Improve Low-Performing Products
Identify least-selling pizzas and:
Improve recipe or pricing
Bundle them with popular items
Remove if consistently underperforming
## 4. Optimize Staffing & Operations
Use peak hour insights to:
Increase staff during busy hours
Reduce staff during slow hours to save cost
## 5. Target Customer Preferences
Since certain categories/sizes perform better:
Focus marketing on high-demand categories
Offer customized deals based on popular sizes
##  6. Seasonal & Time-Based Offers
Use daily trends (like weekends vs weekdays):
Provide special weekend offers
Run campaigns on high-traffic days
## 7. Increase Average Order Value
Encourage customers to buy more by:
combo deals[pizza+drink+sides]
Discounts on bulk orders.


Combo deals (pizza + drink + sides)
Discounts on bulk orders
