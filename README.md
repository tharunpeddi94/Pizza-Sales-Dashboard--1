# Pizza-Sales-Dashboard--1
Excited to Share My Data Analysis Project!  I recently completed a Pizza Sales Analysis Project using SQL and MS Excel.  
The goal of this project is to understand business performance, customer behavior, and sales trends to support data-driven decision-making.
 Tracks key business KPIs like Total Revenue, Total Orders, and Average Order Value,
 Identifies top-selling and least-selling pizzas,
 Analyzes daily and hourly sales trends to find peak business hours,
 Shows sales distribution by category and pizza size,
 Helps understand customer preferences and ordering patterns,
 Provides insights that can help improve sales and business strategy.
